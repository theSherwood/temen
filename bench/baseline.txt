# temen-bench baseline — the tracked signal is the RATIO (temen / wasm), which is far more
# portable across machines than the absolute ns. `--check` flags any ratio that grew past
# the tolerance (temen got relatively slower). The same commit's ratios differ by up to 2x
# between CPU models (#728), so the file keeps a section per CPU model, and a run is checked
# only against its own CPU's section: on a CPU with none, `--check` only reports. The nightly
# bench job's log ends with its run as a section to paste here. Elsewhere:
# cargo run --release -- --save-baseline FILE (writes this machine's section only).
